# Скрипт создания тестовых аккаунтов

## Назначение
Скрипт создаёт 6 тестовых аккаунтов с различными ролями для тестирования функционала приложения Sakbol.

## Использование

### Windows
```bash
cd sakbol_backend
venv\Scripts\activate
python scripts\create_test_accounts.py
```

### Linux/Mac
```bash
cd sakbol_backend
source venv/bin/activate
python scripts/create_test_accounts.py
```

## Результат

После выполнения скрипта:
1. В базе данных создаются 6 пользователей с разными ролями:
   - user (обычный пользователь)
   - parent (родитель)
   - child (ребёнок)
   - tourist (турист)
   - tour_agency (турагентство)
   - user (обычный пользователь)

2. В корне проекта создаётся файл `test_accounts.txt` с данными для входа:
   - Email
   - Пароль (случайный, 12 символов)
   - Имя и фамилия
   - Роль
   - Город

3. Файл `test_accounts.txt` автоматически добавляется в `.gitignore`

## Требования
- Установленные зависимости из `requirements.txt`
- Активное виртуальное окружение
- Инициализированная база данных (выполненные миграции)

## Примечание
- Пароли генерируются случайным образом
- Email имеет формат: `имя.фамилияN@sakbol.test`
- При повторном запуске скрипт пропускает существующие аккаунты
