## 🚀 Как использовать

### Для тур-агента:

1. **Создание группы:**
   - Нажать "Группы" в навигации
   - "+ Создать группу"
   - Ввести название и описание

2. **Приглашение туристов:**
   - Открыть группу
   - Скопировать пригласительную ссылку
   - Отправить туристам

3. **Создание зон:**
   - В группе, вкладка "Зоны"
   - "+ Добавить зону"
   - Нарисовать полигон кликами по карте
   - Или нажать "📍 Моё местоположение" для центрирования
   - Минимум 3 точки

4. **Создание тура:**
   - В группе, вкладка "Туры"
   - "+ Создать тур"
   - Указать длительность (1-1440 минут)

5. **Начало тура:**
   - На главной странице нажать "🚌 Начать тур" (справа вверху)
   - ИЛИ в группе, вкладка "Туры" → "▶ Начать тур"
   - Указать длительность

6. **Мониторинг:**
   - На главной отображается таймер активного тура
   - Показывает название группы и время
   - Кнопка "Завершить" для быстрой остановки

7. **Завершение тура:**
   - На таймере нажать "Завершить"
   - ИЛИ в группе, вкладка "Туры" → "✓ Завершить"

### Для туриста:

1. **Вступление в группу:**
   - Перейти по ссылке `/tour/join/{CODE}`
   - ИЛИ ввести код в форме на странице групп
   - Нажать "Вступить в группу"

2. **Участие в туре:**
   - Местоположение обновляется автоматически (каждые 30 сек)
   - При выходе из зоны агент получает уведомление

## 🔧 API Integration

| Функция | Endpoint | Метод |
|---------|----------|-------|
| Список групп | `/tour/groups/` | GET |
| Создать группу | `/tour/groups/` | POST |
| Детали группы | `/tour/groups/{id}/` | GET |
| Распустить группу | `/tour/groups/{id}/dismiss/` | POST |
| Участники | `/tour/members/?group={id}` | GET |
| Принять участника | `/tour/members/{id}/accept/` | POST |
| Вступить по коду | `/tour/members/join_by_code/` | POST |
| Зоны | `/tour/zones/?group={id}` | GET |
| Создать зону | `/tour/zones/` | POST |
| Сессии | `/tour/sessions/?group={id}` | GET |
| Создать сессию | `/tour/sessions/` | POST |
| Начать тур | `/tour/sessions/{id}/start/` | POST |
| Завершить тур | `/tour/sessions/{id}/complete/` | POST |
| Отменить тур | `/tour/sessions/{id}/cancel/` | POST |
| Обновить местоположение | `/tour/location/update/` | POST |
| Информация о группе | `/tour/invite/{code}/` | GET |

## 📊 Структура данных

### TourGroup
```typescript
{
  id: string (uuid),
  agent: Profile,
  name: string,
  description: string,
  invite_code: string (6 символов),
  invite_link: string,
  is_active: boolean,
  active_members_count: number,
  pending_members_count: number,
  zones_count: number,
  has_active_session: boolean
}
```

### TourSession
```typescript
{
  id: number,
  group: string,
  group_name: string,
  status: 'draft' | 'active' | 'completed' | 'cancelled',
  started_at: string | null,
  ended_at: string | null,
  duration_minutes: number,
  elapsed_minutes: number,
  remaining_minutes: number
}
```

### TourZone
```typescript
{
  id: number,
  name: string,
  description: string,
  polygon: Array<{lat: number, lng: number}>,
  center_lat: number,
  center_lng: number,
  is_active: boolean
}
```
