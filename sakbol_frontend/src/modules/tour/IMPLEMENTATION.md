## 🚀 Как использовать

### Для тур-агента:

1. **Создание группы:**
   - Нажать "Группы" в навигации
   - "+ Создать группу"
   - Ввести название и описание

2. **Приглашение участников:**
   - Открыть группу
   - Скопировать пригласительную ссылку
   - Отправить туристам

3. **Создание зоны:**
   - В группе, вкладка "Зоны"
   - "+ Добавить зону"
   - Нарисовать полигон кликами по карте
   - Минимум 3 точки

4. **Начало тура:**
   - В группе, вкладка "Туры"
   - "+ Создать тур"
   - Указать длительность
   - "Начать тур"

5. **Мониторинг:**
   - Туристы автоматически обновляют местоположение
   - При выходе из зоны - уведомление агенту

### Для туриста:

1. **Вступление в группу:**
   - Перейти по пригласительной ссылке
   - Ввести код приглашения
   - Ождать подтверждения агента

2. **Участие в туре:**
   - Автоматическое обновление местоположения
   - Работает в фоне

## 📊 API Integration

| Функция | API Endpoint |
|---------|--------------|
| Список групп | GET /tour/groups/ |
| Создать группу | POST /tour/groups/ |
| Детали группы | GET /tour/groups/{id}/ |
| Распустить группу | POST /tour/groups/{id}/dismiss/ |
| Участники | GET /tour/members/?group={id} |
| Принять участника | POST /tour/members/{id}/accept/ |
| Зоны | GET /tour/zones/?group={id} |
| Создать зону | POST /tour/zones/ |
| Сессии | GET /tour/sessions/?group={id} |
| Начать тур | POST /tour/sessions/{id}/start/ |
| Обновить местоположение | POST /tour/location/update/ |
